Plan: Convert Paper Entries to Markdown Fenced Divs

Context

Adding a new paper currently requires typing ~8 lines of HTML with four CSS class names to remember (paper-title, paper-authors, paper-venue, paper-links). The goal is to let the user write papers in plain Markdown with standard formatting (**bold**, *italic*, [link](url)), wrapped in a single ::: paper / ::: fenced div block.

The page’s structural layout (two-column sidebar) must stay as raw HTML — there is no Markdown equivalent. Only the paper entries change.

Critical Files

  • index.qmd — split the single {=html} block; papers become fenced divs
  • styles.css — replace .paper-title / .paper-authors / .paper-venue / .paper-links selectors with :nth-child equivalents
  • nav-active.html — update dot-separator JS (no longer uses .paper-links class)
  • _quarto.yml — add anchor-sections: false

Implementation

3. styles.css — replace named paragraph classes with positional selectors

Remove these selectors (or replace): - .paper-title → .paper > p:first-child - .paper-authors, .paper-venue (shared block) → .paper > p:nth-child(2) and .paper > p:nth-child(3) - .paper-authors { margin-bottom: 0.1rem } → .paper > p:nth-child(2) { margin-bottom: 0.1rem } - .paper-venue { margin-bottom: 0.35rem } → .paper > p:nth-child(3) { margin-bottom: 0.35rem } - .paper-links → .paper > p:has(a.paper-link)

All other paper CSS stays unchanged (.paper, .paper-link, .paper-sep, .paper-list).

4. nav-active.html — update dot-separator to find link containers by content

Replace the current .paper-links query:

// Inject dot separators between paper links
var seen = new Set();
document.querySelectorAll('a.paper-link').forEach(function (a) {
  var container = a.parentElement;
  if (!seen.has(container)) {
    seen.add(container);
    Array.from(container.querySelectorAll('a.paper-link')).forEach(function (link, i) {
      if (i > 0) {
        var sep = document.createElement('span');
        sep.className = 'paper-sep';
        sep.textContent = '·';
        container.insertBefore(sep, link);
      }
    });
  }
});

What the user types to add a new paper

::: paper
**Paper Title Here** (2024)

Author One, [Author Two](https://their-url.com), Jean Joohyun Oh

*Journal Name*

[Paper](https://doi-url){.paper-link} [Media Outlet](https://url){.paper-link}
:::

No HTML tags. No CSS class names to remember on paragraphs. Only {.paper-link} on links (so JS auto-opens in new tab and injects dot separators).
